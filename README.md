# StudyMate 📚

StudyMate is a student productivity web application designed to help students organize their academic activities, manage tasks, track assignments, and prepare for examinations.

## ✨ Features

- **Dashboard:** View an overview of your academic activities.
- **Daily Tasks:** Add, manage, complete, and delete daily tasks.
- **Assignments:** Organize and track assignments.
- **Exam Schedule:** Manage upcoming examinations.
- **Consistency Tracker:** Monitor your study consistency and progress.
- **User Authentication:** Secure registration and login.
- **Personalized Data:** Each user has their own data.
- **Responsive Design:** Accessible on desktop and mobile devices.

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- SQLite

## 🚀 Running the Project Locally

1. Clone the repository.
2. Open the project in VS Code.
3. Open the Backend folder in the terminal.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Start the FastAPI server:

```bash
python -m uvicorn main:app --reload
```

6. Open the frontend using VS Code Live Server.
7. Visit the login page and register an account.

Backend API documentation:

http://127.0.0.1:8000/docs

## 🎯 Project Goal

The goal of StudyMate is to provide students with a simple and organized platform to manage their academic responsibilities and build consistent study habits.
